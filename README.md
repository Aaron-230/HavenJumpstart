
# Haven Jumpstart

I made this game from scratch for the Haven Jumpstart.
This is a Simple 2D Platformer with the sole mission of collecting coins. I have added a Menu and End Scene as well and add a Coin System with some Playful Music in the Background.
Use the Arrow Keys for Left and Right Motion and Space to Jump.
Enjoy the Game!
